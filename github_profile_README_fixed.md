# Hi, I'm Sultan Shandon 👋

I build trading and finance tools — strategy backtesters, market-data pipelines, and browser-based simulators that help traders test ideas before risking real money.

I come at software from the problem side: I understand markets and trading deeply, and I build the tools that solve real problems in that space. My work is grounded in the belief that a tool isn't done when it runs — it's done when you've verified it does the right thing under real conditions.

---

## 🔧 What I build

**Alpha Breakout Lab — Website & Trading Tools**
The codebase behind [alphabreakoutlab.com](https://alphabreakoutlab.com) — a free, browser-based moving-average crossover strategy simulator with supporting tools and educational content. Pick stocks, set moving averages, run a backtest, and see entries, exits, an equity curve, and per-stock results. Live and free, no signup.

**Trader's Journal**
A browser-based trading journal for logging trades and tracking performance weekly, monthly, and yearly — with charts, stats, and full import/export so your data stays portable. Built on the idea that you can't improve what you don't measure.

**FDA PDUFA Catalyst Calendar**
A tool that tracks and ranks upcoming FDA PDUFA dates — the regulatory decision deadlines that move biotech and pharma stocks. Includes a watchlist, a plain-language glossary, and catalyst alerts.

## 🧠 How I work

- Understand what "working" actually means before trusting a result.
- Test one variable at a time so I know what caused what.
- Model real-world conditions (costs, friction, edge cases), not just the convenient ones.
- Verify the inputs — the silent data bugs cause the worst damage.
- Follow the evidence, even when it kills an idea I liked.

I use modern tools, including AI, to move fast on implementation — but the judgment about what to build, whether it's correct, and when it's actually done is what I bring.
